# Фронтенд — отдельный SPA поверх JSON API, без Inertia

Каркас приложения собирался на Blade с серверным рендерингом. Дальше проект переходит на Design First: контракт описывается в TypeSpec, из него генерируется OpenAPI, а из неё — клиентский SDK, которым пользуется фронтенд. В серверном рендеринге такому SDK нечего делать, поэтому фронтенд становится отдельным SPA на Vue и TypeScript: Laravel отдаёт JSON API и одну оболочку, весь интерфейс живёт на клиенте.

Inertia рассматривался и отвергнут, хотя именно на нём построены официальные стартер-киты Laravel. Он передаёт данные пропсами с сервера в обход HTTP-API, и сгенерированный клиент остался бы без применения — то есть проблема, ради которой мы уходим от Blade, воспроизвелась бы один в один.

## Consequences

- Главная страница и заглушка страницы записи переезжают из Blade в роуты SPA. Blade остаётся только оболочкой.
- Тесты этих страниц переписываются: серверные проверяют API и отдачу оболочки, поведение интерфейса проверяется на клиенте.
- ADR-0002 (длительность встречи в конфиге) теряет силу по мере того, как длительность становится свойством типа события и уезжает в контракт.
