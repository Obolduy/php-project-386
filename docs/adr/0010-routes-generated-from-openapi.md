# Маршруты генерируются собственной командой из OpenAPI

Требование шага — серверные артефакты, включая маршруты, генерируются из спецификации. Исследование показало, что связка `jane-php` и валидаторов OpenAPI генерирует типы и проверяет соответствие, но маршрутов не даёт; заготовки маршрутов есть только у `openapi-generator`, а он требует Java.

Мы пишем небольшую Artisan-команду, которая читает сгенерированную OpenAPI и выписывает `routes/api.php`: путь, метод и контроллер выводятся из `paths` и `operationId`. Java не ставим.

Альтернативы отвергнуты: тянуть Java ради одного генератора — тяжёлая зависимость в CI и в Docker-образе; ограничиться проверкой «маршруты совпадают со спецификацией» — оставило бы требование шага невыполненным.

## Consequences

- `routes/api.php` — сгенерированный файл, руками не правится.
- Соглашение: `operationId` вида `MeetingTypes_list` разворачивается в `MeetingTypesController@list`.
- Команда становится частью общей цепочки генерации.
