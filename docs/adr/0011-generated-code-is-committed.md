# Сгенерированный код коммитится в репозиторий

OpenAPI из TypeSpec, клиентский SDK, PHP-типы и `routes/api.php` попадают в репозиторий, а не в `.gitignore`.

Иначе сборка Docker-образа и прогон CI начинают требовать полной цепочки генерации: Node с TypeSpec ради серверного образа, порядок шагов, кеш. Закоммиченные артефакты делают образ воспроизводимым из одного `composer install` и `npm ci`.

Расхождение ловится в CI шагом `git diff --exit-code` после перегенерации: если сгенерированное не совпадает с закоммиченным, прогон падает.

## Consequences

- Диффы в пул-реквестах становятся шумнее.
- Правка сгенерированного файла руками не ломается молча, а падает в CI.
